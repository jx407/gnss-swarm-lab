# 契约增补 v8（2026-10-06）——§14 带环路滤波的码跟踪环（DLL）

阅读顺序：本文件 + `CONTRACT.md` §0 + `CONTRACT-v7.md` §13-rev。**不得修改**既有函数。

## §14 `GNSS.trackDll(signals, opts)`

```js
GNSS.trackDll(signals, opts) -> { chips: [Number], disc: [Number], locked: Boolean }
```

- `signals`：每个历元一个 `GNSS.makeSignal` 产物（长度 N ≥ 2）。信号是由**物理**产生的，
  本模块只能看信号，不得读取任何"真值"字段（`signals[i].codePhase` 在测试里被故意改成假值，
  读它就必然失败）。
- `opts`：`alpha`（默认 0.4）、`beta`（默认 0.06）、`spacingChips`（默认 0.5）、
  `init`（可选 `{chips, dopplerHz}`；不给时第 0 历元用 `GNSS.acquire(signals[0], {})` 初始化）。
- 第 0 历元输出初始化估计；第 e≥1 历元：

  1. **早迟门**（注意 `correlateAt` 的镜像约定，必须用 `GNSS.chipsToCorrelateOffset` 折算）：
     `E = correlateAt(sig, chipsToCorrelateOffset(g + s, fs), dop, sig.ms)`，`L` 同理取 `g − s`；
     `d = (E + L) > 0 ? (E − L) / (E + L) : 0`（`d > 0` 表示真值在 g 前方）。
  2. **PI 环路滤波**：`acc = beta * (acc + d)`；`g = g + alpha * d + acc`；`g` 归一到 [0,1023)。
- 返回 `chips`（每历元环路输出，chip ∈ [0,1023)）、`disc`（判别器序列）、`locked`（全部输出有限
  且判别器未越界 → true）。
- 纯函数、确定性、不修改 `signals`/`opts`；非法输入（非数组、长度 < 2、元素缺 `i`）返回
  `{ chips: [], disc: [], locked: false }`，不抛异常。
- ES5 兼容（`var`/`function`），中文注释。

### 为什么二阶（PI）而不是一阶
一阶环（`beta = 0`）对**匀速运动**有稳态滞后，但它在这里的主要失效模式是**失锁**（牵入范围不足）：
一旦误差超出早迟门主瓣，判别器输出≈0，环路再也拉不回来，误差随历元线性增长。二阶环的积分项把
牵入范围显著扩大（实测下界：α ≥ 0.2 左右才锁得住 0.27 chip/历元的斜坡；α=0.15 时二阶环也失锁）。
本仿真里"匀速"= 码相位每历元按固定斜率增长（相对视线速度造成的码相位漂移）。

**不要**用"一阶环稳态滞后 = 斜率/alpha"这类连续时间教科书写法来推断本实现：它没考虑判别器
在工作点附近的增益（理论 2.0、实测 ≈1.7，见竞标 B 版标定）与饱和，实测偏差可达数倍。

### 与"多历元平均"的本质区别（判据用数字说话）
`tests/test-dll.js` 实测（20 历元、SNR −20 dB、4 采样/chip、斜率 0.27 chip/历元 ≈ 80 m/历元）：

| 方法 | 静态残差 RMS | 斜坡稳态滞后（0.27 chip/历元） |
|---|---|---|
| 多历元快照平均 | ~1/√N 下降 | **≈752 m（= 斜率·(N−1)/2，结构性的，平均消不掉）** |
| 一阶环 α=0.4, β=0 | 15 m | 34 m |
| **二阶环 α=0.4, β=0.06** | 15 m | **15 m** |
| 一阶环 α=0.25, β=0 | — | **386 m（失锁）** |
| **二阶环 α=0.25, β=0.06** | — | **55 m（仍锁定）** |

**注意**：一阶环的行为不是简单的"稳态滞后 = 斜率/α"。实测（`review/probe-dll-gain.js`）在
α ≤ 0.25 时它**直接失锁**：误差随历元线性增长（α=0.25 → 1.32 chip，α=0.15 → 3.38 chip），
因为一旦误差超过早迟门的主瓣，判别器输出≈0，环路再也拉不回来（经典 DLL 牵入范围问题）。
积分项（β）把牵入范围显著扩大——这才是二阶环在本仿真里最值钱的地方。

注意 4 采样/chip 的模型下限：C/A 码每 chip 内取值恒定 ⇒ 码相位不可区分区间 = 1/采样率 = 0.25 chip
≈ 73 m，任何估计器静态误差下限 = ±0.125 chip ≈ ±37 m（见 `tests/test-signal-conv.js`）。
所以判据里的静态门槛用 ≤0.15 chip，而不是更小的数——这是模型极限，不是算法让步。
