# 契约增补 v10（2026-10-06）——§16 载波跟踪环（Costas PLL）+ lib 两个基元

## §16.0 lib/signal.js 新增基元（本次已实现，向后兼容）
- `makeSignal(opts)` 新增 `carrierPhaseRad`（载波初相，弧度，默认 0）。默认值下与旧版**逐位一致**（16 套既有判据全绿）。
- `GNSS.correlateIQ(sig, codePhaseSamples, fNcoHz, phiNcoRad, ms)` → `{ I, Q, amp }`：
  按本振 `θ_j = 2π·fNco·t_j + φNco` 同时剥离载波与码，返回 prompt 的两路累加值。
  码相位沿用 `correlateAt` 的**镜像约定**，调用方必须先经 `GNSS.chipsToCorrelateOffset` 折算。

## §16.1 `GNSS.pllTrack(epochs, opts)`

```js
GNSS.pllTrack(epochs, opts) -> { phase: [N], freq: [N], disc: [N], locked }
```

- `epochs[e] = { t, sig }`：`sig` 是 `GNSS.makeSignal` 产物（**真值相位只存在于信号的生成参数里**，
  实现不得读取 `sig.carrierPhaseRad` / `epochs[e].truth` 之类字段——判据里这些字段会被故意改成假值）。
  `t` 是该历元相对上一历元的秒数（首历元也用它算频差）。
- `opts`：`codeChips`（码相位，**必填**，由码环/DLL 提供）、`fNco0`（本振初始频率 Hz，默认 0）、
  `phi0`（本振初始相位 rad，默认 0）、`alpha`（默认 0.4）、`beta`（默认 0.02）。
- 每历元：
  1. `off = GNSS.chipsToCorrelateOffset(codeChips, sig.fs)`；
     `{I,Q} = GNSS.correlateIQ(sig, off, fNco, phiNco, sig.ms)`（本振相位/频率是**上一历元**的输出）；
  2. **鉴相**（`opts.disc`，默认 `'atan'`）：
     * `'atan'`：`d = atan2(Q, I)` —— 相位锁定型（pure PLL），小误差下线性、增益 ≈1；
       **对 180° 数据位翻转不免疫**（翻转时 I 变号 → d → ±π，环路被踢）。
     * `'costas'`：`d = I·Q/(I²+Q²)` —— 归一化 Costas 鉴相，**对复幅度整体取反不变**（数据位 180° 翻转让 I、Q 同时变号，分子 (−I)(−Q)=I·Q 不变），
       数据位翻转时 d≈0、环路纹丝不动（小误差下增益同样 ≈1）。
     实测（`review/probe-pll-flip.js`，翻转插入在第 20 历元，α=0.4/β=0.02、snrDb=−20 dB）：
     `atan` 翻转后稳态 max|d|=3.06（被踢到翻转后的相位）；`costas` 翻转后稳态 max|d|=0.10（NCO 相位连续）。
     两者在**无翻转**的平滑相位下表现一致（后 20 历元 mean 0.008–0.009 rad、rms 0.026–0.027 rad）；
     但大误差下增益不同（无噪标定：偏移 1.0 rad 时 atan 输出 1.000、costas 输出 0.455），
     所以下面的 α/β 标定针对 `atan`，切 `costas` 只在大误差牵入段略慢。
  3. **PI 环路**：`acc += beta·d`；`phiNco += alpha·d + acc`（`phiNco` **不取模**）；
  4. 输出 `phase[e] = phiNco`、`disc[e] = d`；
     `freq[e] = e === 0 ? 0 : (phase[e] − phase[e−1]) / (2π·t)`（**残余频差** Hz，与真值同号）。
- `locked`：所有输出有限，**且后半段历元（`e ≥ ⌊N/2⌋`）的 `max|disc| ≤ 0.5 rad`** 为 true。
  （用稳态口径而不是全程：初相偏 1.5 rad 时前几历元的鉴别器必然很大，那叫**牵入**，不叫失锁。）
- 纯函数、确定性、不修改 `epochs`/`opts`；非法输入（非数组、空、缺 `sig`、缺 `opts.codeChips`）返回
  `{ phase: [], freq: [], disc: [], locked: false }`，不抛异常。ES5 兼容，中文注释。

### 为什么二阶（PI）而不是一阶 —— 与码环同一条道理，但量级不同
一阶环（`beta=0`）对**恒定残余多普勒**有稳态相位滞后 `≈ 斜率/alpha`；二阶环用积分项把匀速滞后压到接近零。
参考实测（原型 `review/proto-pll.js`，N=40、dt=5 ms、snrDb=−20 dB ≈ 后相关 21 dB）：

| 场景 | 一阶 α=0.15 | 二阶 α=0.4/β=0.02 |
|---|---|---|
| 静态 φ=0.7 rad | 后 20 历元均值 −0.012 rad | **−0.033 rad**（抖动 rms 0.041） |
| 残余多普勒 2 Hz（0.063 rad/历元） | **+0.433 rad** | **+0.008 rad ≈ 0（这就是积分项的作用）** |
| 多普勒变化率 0.002 rad/历元² | **+0.849 rad** | **+0.093 rad（还有残余，要 3 阶环才能消）** |
| 初相偏 1.5 rad 的牵入 | 0.015 rad | 0.014 rad |

三条写完判据后复核过的真实行为（**注意第 ① 条推翻了我最早的说法**）：
①**二阶环对恒定多普勒的稳态滞后实测 ≈0**（后 20 历元均值 0.008 rad）——我先前以为 4 ms 相干积分会带来
"半历元偏差"，实测证伪；真正有残余的是**多普勒变化率**（0.093 rad，因为 2 阶环只有两个积分器）。
②**噪声与带宽权衡**：α 越大跟动态越快、静态抖动越大（实测 α=0.15/β=0 → rms 0.039 rad，
α=0.4/β=0.02 → 0.041 rad；差距不大，但趋势稳定）。
③**本振频率不要直接吃环路噪声**：把 `acc` 折算成频差再喂进本振频率（`fNco = fTrue + acc/(2πdt)`）
实测反而更差（斜坡 rms 0.031 → 0.043 rad），所以契约采用"频差只体现在相位累加"的写法。

### 实测牵入范围、鉴别器增益与 `locked` 的固有局限（竞标 B 版实测，α=0.4/β=0.02）

| 鉴相器 | 牵入成功范围（初相误差） | 失效模式 |
|---|---|---|
| `atan` | 0.2–3.0 rad（全程收敛） | — |
| `costas` | ≤ 1.4 rad | ≥ 1.6 rad（π/2 附近）收敛到**错误吸引子**（末值 ≈ −3.08 rad） |

无噪增益标定（真实偏移 → 鉴别器输出）：`atan` 恒为 1.000（0.2/0.5/1.0/1.5/2.0 rad 全线性）；
`costas` 为 0.974 / 0.841 / 0.455 / 0.047 / −0.189 —— 小误差下两者等价，大误差下 Costas 增益塌陷。

**`locked` 的固有局限（必须在文档里写清）**：`locked` 只判断"稳态鉴别器足够小"，**不能**判断
"锁到了正确相位"——Costas 在 1.6 rad 初相下会锁到错误吸引子，但稳态 |d| 很小、于是报告 `locked=true`。
真实接收机必须结合相关幅度、频差稳定性等联合判断；本工作台用已知真值做教学演示，所以判据里
用"与真值的稳态误差"而不是只看 `locked`。

噪声—带宽权衡（β = 0.05α，静态 rms / 2 Hz 斜坡滞后）：α=0.1 → 0.1553 / 0.1226；
α=0.2 → 0.0848 / 0.0166；**α=0.4 → 0.0445 / 0.0076（平衡点）**；α=0.8 → 0.0483 / 0.0072。
