# 契约增补 v12（2026-10-06）——§18 双频消电离层组合（iono-free）

## §18 `GNSS.ionoFree*`

```js
GNSS.ionoFreeWeights(f1Hz, f2Hz) -> { k, w1, w2, amp, ok }
GNSS.ionoFree(pr1, pr2, f1Hz, f2Hz) -> Number
GNSS.ionoFreeNoiseAmp(f1Hz, f2Hz) -> Number
```

- 定义：`k = (f1/f2)²`；组合 `IF = w1·pr1 + w2·pr2`，其中 `w1 = k/(k−1)`、`w2 = −1/(k−1)`。
  这样当 `pr1 = R + I`、`pr2 = R + k·I`（同一几何/钟差 R + 各自频率的电离层延迟）时，
  `IF = R` —— **电离层被精确消掉**，而 R（几何+钟差+对流层等两频相同项）原样保留。
- `amp = hypot(w1, w2) = sqrt(k²+1)/(k−1)`：两频白噪声（等 σ）经组合后的**噪声放大倍数**。
  GPS L1/L2：k = 1.646944，w1 = 2.545728，w2 = −1.545728，**amp = 2.978255**。
- 非法输入（f1/f2 非有限、≤0、`f1 === f2`、pr 非有限）→ 数值函数返回 `NaN`，
  `ionoFreeWeights` 返回 `{ k: NaN, w1: NaN, w2: NaN, amp: NaN, ok: false }`；**一律不抛异常**。
- 纯函数、确定性；ES5 兼容；中文注释。

### 为什么值得单独做判据
"消掉电离层"很容易写对，但**噪声放大倍数**和**两频相同项必须原样保留**这两条常被写错（符号反了、
或用 sqrt(k) 之类近似）。判据里既有解析检查（`pr1 = R+I, pr2 = R+k·I → IF = R`，多组 R/I），
也有蒙特卡洛实测的噪声放大（σ=1 m、4000 样本 → 实测 std 应 ≈ 2.978±0.08），还有频点通用性检查
（换成 Galileo E1/E5a 时 k、amp 必须按同一公式给出，而不是把 GPS 的常数写死）。

### 与误差预算面板的关系
`app/70-atm.js` 里的三情景对照（不改正 / 模型改正 / 双频）原本把 IF 组合三行内联在面板里、
只有**单次抽样**。本模块把它抽成有判据的基元，供定位面板做**蒙特卡洛**版本：
"模型残差 vs 组合噪声放大 2.978" 会在定位 RMS 上直接体现（见本轮 `app/40-pos.js` 的改动）。

### 三条容易搞错的补充（竞标 B 版的推导与实测，已核对）

1. **权重不是"按噪声最优"，而是消电离层约束下的唯一解**：要求 `α+β=1`（共同项原样保留）且 `α+k·β=0`
   （电离层精确消掉）后，解唯一 = `k/(k−1)`、`−1/(k−1)`，**与两频噪声无关**。
   只有当**放松**"精确消掉"这个约束（部分消电离层 / 允许残余）时，才有按 σ 加权的自由度。
   两频噪声不等时，组合噪声不是 `amp·σ`，而是 `hypot(w1·σ1, w2·σ2)`
   （例：σ1=1、σ2=2 → 4.005 m，而等噪声时是 2.978 m）。
2. **不同频对的噪声放大差别很大**（固定 f1 = L1/E1）：
   | 频对 | k | amp |
   |---|---|---|
   | L1/L5（1176.45 MHz） | 1.7933 | **2.588（最小）** |
   | L1/B2a（1176.45） | 1.7608 | 2.662 |
   | L1/L2（1227.60） | 1.6469 | 2.978 |
   | L1/E6（1278.75） | 1.5178 | 3.510 |
   | L2/L5（1227.60/1176.45） | 1.0891 | **16.64（频率太近，几乎不可用）** |
3. **三频**：三频组合可在"消电离层"之外再压低噪声（B 版估：按 1/amp² 加权多个双频组合，
   最优 amp ≈ 1.94，比单个 L1/L5 再降 25%），并可同时构造消几何（GF）组合用于电离层估计与周跳检测。
   本工作台只做双频。

### 定位面板（app/40-pos.js）的实测交叉点（重要：**不能**想当然地说"强扰动就该用双频"）
蒙特卡洛 50 次、同批噪声、8 颗星（`qa/probe-iono-sweep.js` 扫参）：

| 活跃度 | σ | 不改正 | 模型改正（改掉 70%） | 双频消电离层 |
|---|---|---|---|---|
| ×1（L1 最大斜距延迟 25.8 m） | 2 m | 7.5 m | 7.4 m | 22.1 m |
| ×20（433 m） | 1 m | 23.3 m | **8.0 m** | 11.1 m |
| ×20 | **0.5 m** | 23.0 m | 7.2 m | **5.5 m ← 只有低噪声才反超** |

两条反直觉结论（都已写成判据 `qa/check20.js`）：
①"不改正"的误差**不随活跃度线性放大**——各星电离层的**共同模态**被接收机钟差吸收，
   ×1 → ×20 只从 7.5 涨到 23.3 m（而斜距延迟从 25.8 涨到 433 m）；
②双频要想反超模型改正，**σ 必须足够小**（实测需 ≤0.5 m），否则 2.978× 的噪声代价先把它拖垮。
