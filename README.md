A **single-file, offline GNSS teaching workbench** that runs entirely in the browser. Ten interactive lab
tabs take you from constellation geometry and C/A codes all the way to acquisition, positioning, multipath,
RAIM, ionospheric budgets, cold start and carrier tracking — every panel lets you change parameters and watch
the numbers and plots respond immediately.

> No build step, no CDN, no fonts, no telemetry: one HTML file with everything inlined. Double-click and it runs.

## What it is

A hands-on GNSS lab for teaching and self-study. Instead of reading formulas, you drag a slider and see a
correlation peak drown in noise, watch PDOP change when you switch satellite systems, or watch a cold-start
navigator go from "no fix" to a first position.

Everything is computed locally in JavaScript — no server, no WASM blob, no network calls:
constellations from analytic circular orbits (optionally a real GPS snapshot), C/A codes generated per
IS-GPS-200, 2-D code-phase × Doppler acquisition, least-squares positioning, DLL / PLL / Hatch smoothing,
an 8-state CV Kalman filter, and RAIM protection levels.

## Features

- **Ten interactive tabs** — see the table below.
- **Real computation** — the plots are results, not illustrations.
- **Judged algorithms** — every core module in `winners/` ships with its own Node test suite
  (**21 suites, 505 assertions**, all green).
- **Single file & offline** — `outputs/gnss-swarm-lab.html` (~555 KB); zero external requests.
- **Accessible** — ARIA tablist with arrow-key navigation, roving `tabindex`, `nav`/`main`/`region`
  landmarks, `role="img"` + `aria-label` on all 26 canvases, `aria-valuetext` on sliders, and a 44-entry
  glossary in a collapsible block.
- **Responsive** — designed and verified from 320 px to 1280 px: no horizontal overflow, no clipped chart text.

## The ten tabs

| Tab | What you see | What you can change |
|---|---|---|
| Constellation | Sky plot, 24 h DOP curves, visible sats / PDOP / GDOP | Satellite systems (GPS / +Galileo / +BeiDou), real vs synthetic constellation, latitude, mask, time |
| C/A code | Autocorrelation peak, cross-correlation floor, chip strip | PRN pair |
| Acquisition | Code-phase × Doppler search surface, correlation profile | SNR, Doppler, code phase |
| Positioning | Equal-weight vs elevation-weighted solution, ionosphere scenarios | Pseudorange σ, satellite count, ISB, ionospheric activity |
| Multipath | Reflection geometry, extra delay, bias magnitude | Wall distance / height / azimuth |
| RAIM | Normalized residuals, leverage, HPL/VPL vs alarm limit | Inject a blunder on one satellite, σ |
| Global geometry | 24 h median PDOP for 16 sites (plus 95th percentile) | Latitude, time |
| Error budget | Ionospheric delay curves, correction ratio, dual-frequency cost | Carrier, correction ratio, presets |
| Cold start | Acquisition → tracking → fix: TTFF staircase and accuracy ladder | Front-end bandwidth, ADC rate, SNR, epoch count |
| Carrier tracking | IQ constellation, phase error, discriminator output, Hatch smoothing | Loop order, discriminator, C/N0, cycle slip |

## Project layout

```
outputs/            build artifacts — gnss-swarm-lab.html (standalone) / .inline.html (host fragment)
docs/               screenshots + index.html (GitHub Pages entry, generated by build-all.sh)
work/gnss-swarm/    sources and tests
  ├─ shell.html     page skeleton (10 panels, glossary, appendix)
  ├─ app/           CSS + canvas drawing modules (C.label / labelTick / labelFit primitives)
  ├─ winners/       judged algorithm modules (manifest.txt decides what gets bundled)
  ├─ tests/         21 Node test suites (run-all.sh)
  ├─ qa/            browser checks check14–25 and measurement probes
  ├─ CONTRACT-*.md  behaviour contracts that the tests encode
  └─ HANDOFF.md     full development/audit log (nine rounds, including the mistakes)
review/ds41/        independent audit reports written by sub-agents
```

## Rebuild from source

```bash
bash work/gnss-swarm/build-all.sh
```

Bundles `work/gnss-swarm/{shell.html,app/*,winners/*}` into `outputs/` and refreshes `docs/index.html`
(the Pages entry). The script defaults to a machine-specific Node path — set `NODE=/path/to/node` or edit the
first line of the script.

## Verification

```bash
cd work/gnss-swarm
bash tests/run-all.sh                 # 21 Node suites (core algorithms)
node qa/check14.js                    # …through check25.js: 12 browser suites (Playwright/Chromium)
node qa/probe-layout2.js              # 10 tabs × 3 widths: overflow / height / blank canvases
node qa/probe-chrome.js               # 5 widths: heading, nav rows, glossary, horizontal overflow
node qa/probe-xoverflow.js            # internal overflow of #gnss-lab
node qa/probe-sweep.js                # extreme parameter sweep (all controls to min/max) × 2 widths
node qa/probe-coldsatclip.js          # cold-start canvas text overflow
node qa/probe-gecko.js                # optional: Gecko  (needs `playwright install firefox`)
node qa/probe-webkit.js               # optional: WebKit (needs `playwright install webkit`)
node qa/probe-pages.js                # verifies the deployed GitHub Pages build
```

Measured on the released build (SHA-256 `9e3150ad…`):

- **Tests** — 21 Node suites green; browser checks **check14–25 (344 asserts) pass**, 0 console issues.
- **Chart text health** — at 320 / 360 / 420 / 980 px: **0 clipped labels, 0 overlapping labels**; the same
  holds for the extreme parameter sweep (2 widths × 15 scenarios).
- **Three engines** — Blink (Chromium 151 / Chrome 154 / Edge 149), Gecko (Firefox 153), WebKit 26.5:
  **0 console errors/warnings, 0 page errors, 0 failed requests**; load 58–315 ms; `#gl-sky-pdop` = 2.81 everywhere.
- **Cross-engine numeric agreement** — cold-start results differ by ≤ 6.3e-8 relative (floating point);
  Gecko and WebKit are bit-identical, PLL locks 6/6 in every engine.
- **Stress** — 50-tab storm, 4×40 slider storm, 12 resize storms, 20 details toggles, cold start interrupted by
  tab switches, keyboard-only walkthrough: no crashes, no stuck states, 26/26 canvases non-empty.
- **Live page** — `qa/probe-pages.js` against the Pages URL: 10 tabs, 26 canvases, sky plot drawn, 0 console issues.

> **About paths in the probes.** Scripts under `qa/` and `review/` were written during development and contain
> the author's absolute paths (`PAGE = file:///D:/…`, `createRequire('C:/Users/…/node_modules/')`). They contain
> no secrets, but you must point them at your own paths to run them. The page itself and `tests/` use no
> absolute paths.

## Known limitations

1. **The cold-start tab computes automatically on first visit** — roughly 4–7 s depending on engine and load
   (Chromium ≈5 s, Firefox ≈3.9 s, WebKit ≈7.1 s). A progress bar plus a live status line show what is
   happening, and you can switch tabs while it runs.
2. **Printing outputs only the active tab** (unvisited panels are genuinely empty canvases).
3. **Real-device touch, DPR > 1 and non-headless GPU were not verified** — 44 px touch targets were checked in
   device emulation only.
4. The glossary has 44 entries but is not exhaustive; niche terms may still be unexplained.

## Contributing

Issues and pull requests are welcome. Two rules keep the project honest:

1. **Stay offline** — no external assets, fonts, CDNs or trackers in the page.
2. **Keep the tests green** — run `bash tests/run-all.sh`; if you touch drawing code, also run
   `qa/probe-sweep.js` and the chart probes so no label leaves its canvas.
