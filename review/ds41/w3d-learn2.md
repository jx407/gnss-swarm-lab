## 附录 A：顶部「术语速查」实读结果（`details.gl-glossary`）

- `summary` 原文：**「术语速查（PDOP / RAIM / HPL / C/N0 / NEES / chip / spc …，点开）」**
- 默认状态：**收起**（`<details>` 无 `open` 属性，实测已确认）
- **实际条目数 = 15 条**（任务书写的"17 条"与 DOM 不符，此处以 DOM 为准）；展开后非空白字符数 **614**
1. PDOP / GDOP / HDOP / VDOP：几何精度因子——卫星在天上分布越开越小；PDOP < 2 算好几何，> 6 表示卫星挤在一起。
2. RAIM：接收机自主完好性监测——用多余观测互相校验，找出坏星。
3. HPL / VPL：水平 / 垂向保护限级，即误差的置信上界（本页对照 40 m 水平告警限）。
4. nmr：归一化残差（残差 ÷ 它的标准差）——RAIM 用它挑最可疑的那颗星。
5. 杠杆：帽子矩阵对角元；越接近 1，这颗星出错越容易被解自己吸收、越难检出。
6. chip：C/A 码的一个码片；1 chip = 1/1.023 MHz ≈ 0.978 μs ≈ 293 m。
7. spc：samples per chip，每个码片采几个点；采样率高，码相位才分得细。
8. C/N0：载噪比，衡量信号强弱；越高表示噪声越小。
9. σ：噪声标准差。图上写「峰 10.7σ」＝峰高是噪声的 10.7 倍；定位页的 σ 是伪距噪声（米）。
10. RMS：均方根误差——本页所有「误差 … m」都是 RMS。
11. DRMS：二维径向 1σ 圆半径，散点图里的虚线圈就是它。
12. TTFF：Time To First Fix，首次定位用时。
13. NEES：归一化估计误差平方，检查滤波器有没有「过度自信」（理论值 3）。
14. Costas：对载波 180° 相位翻转不敏感的鉴相器；DLL / PLL：延迟锁定环 / 相位锁定环。
15. lag：相关函数的时延自变量（单位 chip）；历元：一个采样时刻（本页多为 1 ms 或 1 s）。

**首屏 3 行导语**（`#gnss-lab` 头部，非折叠）：
1. 这页把 GNSS 从星座、捕获到跟踪串成可动手比较的实验。
2. 先看每页的短读法，再看图上的实际变化；需要推导与实测口径时再展开「详细说明」。
3. 切换参数时，只比较相同设置下的结果，避免把不同条件混在一起。
